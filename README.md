Interactive Sales System

Интерактивная система продаж для компании по производству и продаже цемента.

Описание проекта

Система предназначена для автоматизации обработки заказов, управления акциями для клиентов и расчёта скидок. 
Проект реализован на Java Core без использования баз данных и сторонних фреймворков. 
Хранение данных организовано в памяти приложения с использованием коллекций Java.

Основной функционал

* Создание и обработка заказов клиентов
* Управление акциями и скидочными программами
* Автоматический расчёт скидок в зависимости от условий
* Хранение данных о клиентах и заказах в коллекциях
* Базовая бизнес-логика продаж

Бизнес-логика

* Скидка рассчитывается автоматически на основе заданных правил
* Акции могут применяться к конкретным клиентам или группам
* Заказ проходит обработку через фиксированные этапы

Стек технологий

* Java Core
* Collections Framework

Особенности проекта

* Реализована собственная бизнес-логика расчёта скидок
* Хранение данных в памяти приложения с использованием списков
* Чёткое разделение слоёв приложения
* Фокус на обработке бизнес-процессов
